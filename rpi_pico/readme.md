# converter/hp_pavilion_plus_14_eh/rpi_pico

![converter/hp_pavilion_plus_14_eh/rpi_pico]

This is a converter PCB for HP Pavilion Plus 14-eh keyboards (Sunrex SG-A9910-XUA / GCNR844DS), based on the Raspberry Pi Pico (RP2040).

* Keyboard Maintainer: [KikuchiMakoto](https://github.com/KikuchiMakoto)
* Hardware Supported: Custom RP2040 converter PCB with HP Pavilion Plus 14-eh 40-pin FPC keyboard
* Hardware Availability: [Custom PCB](https://github.com/KikuchiMakoto)

Make example for this keyboard (after setting up your build environment):

    make converter/hp_pavilion_plus_14_eh/rpi_pico:default

Flashing example for this keyboard:

    make converter/hp_pavilion_plus_14_eh/rpi_pico:default:flash
